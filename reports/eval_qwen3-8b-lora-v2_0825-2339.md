  ### 404 오류란?
  404는 **요청한 페이지가 서버에 존재하지 않거나, 잘못된 경로로 요청했을 때** 발생하는 HTTP 상태 코드입니다.

  - `https://example.com/nonexistent-page`

  ---
  
  ### 404가 발생하는 이유:
  1. **URL이 잘못 입력됨** (예: 오타)
  2. **페이지가 이동하거나 삭제됨**
  3. **서버 설정 오류** (예: 잘못된 경로 설정)
  4. **링크가 잘못
  ```

  def fibonacci(n):

          result.append(a)
